SYNCHRONOS — COMPLETE 60 / RESPONSIVE READER & PORTRAIT (64)

실행에 필요한 웹 파일, 이미지, 원본 벡터, 웹 서체, 원본 책·포스터 PDF를 포함한 전체본입니다.

1. ZIP을 새 위치에 압축 해제합니다.
2. START.command를 더블클릭합니다.
3. 열린 터미널 창은 실행 중 유지합니다. 종료는 Control+C.

파일을 더블클릭해서 index.html을 직접 열면 데이터 읽기가 차단될 수 있습니다.
START.command가 열리지 않으면 이 폴더에서 아래 명령으로 서버를 실행합니다.
python3 -m http.server 4174 --bind 127.0.0.1
그런 다음 http://127.0.0.1:4174/ 를 엽니다.

GitHub Pages에는 index.html, CSS·JS·MJS 파일과 assets 전체를 같은 위치에 올립니다.
특히 이번에 추가된 assets/book-pages 폴더 40개 파일을 포함해야 합니다.
원본 PDF와 벡터 및 fonts 폴더도 모두 포함되어 있습니다.

개선 65 (안착 시 페이지 깜빡임 제거):
- 원인: 넘김이 끝나는 프레임에 책장을 그리던 화면을 숨기는 것과 아래 정지 페이지의 이미지 교체가 동시에 일어나, 새 이미지가 디코딩되는 짧은 순간 페이지가 비어 보였습니다.
- 수정: 최종 페이지 이미지를 책장 아래에 먼저 교체하고 디코딩이 끝난 뒤에야 책장 화면을 숨깁니다. 넘긴 모습이 그대로 유지되며, 뒷장이 비치거나 겹쳐 보이지 않습니다. 넘김 취소(되돌아감)와 연속 입력, 앞·뒤 방향 전환에도 동일하게 적용됩니다.
- 수정 파일: book-turn.js, index.html(캐시 버전)

개선 64:
- 책장이 놓일 때 그래픽이 다시 로딩되며 깨져 보이던 현상 수정: 넘김에 쓰인 것과 같은 고해상도 이미지를 정지 페이지에도 바로 사용합니다(저해상도→고해상도 교체 제거). 역방향↔순방향을 바꿔 넘겨도 동일합니다.
- 가운데(제본선) 음영 수정: 페이지 그림자가 옆 페이지 안쪽으로 번져 정지 상태 가운데만 과하게 진하던 문제를 바로잡았습니다(fit-layout.css). 넘어가는 동안과 안착 후 가운데 음영이 같은 값으로 이어집니다.
- 3번 섹션: 회색 그림이 거칠게 깨져 보이던 원인(미리보기 webp의 투명도 노이즈)을 원본 벡터에서 다시 생성해 해결했고, 파일 용량도 절반으로 줄였습니다(assets/previews/graphic-*.webp). 양피지 이미지를 함께 미리 불러오고, 화면에 보이는 3개 선택지의 벡터를 미리 받아 결과 화면이 빨라졌습니다.
- 1번 섹션: 엽서 상세의 한 줄 소제목 등 한글이 궁서체(기본 명조)로 나오던 곳을 Pretendard로 바꿨습니다(서체 목록에서 serif 대체 제거).

개선 63 (넘김 중 음영):
- 넘어가는 책장에 휘어짐에 따른 입체 음영(빛 방향, 제본선 쪽 접힘 그늘, 바깥쪽으로 갈수록 어두워짐)을 적용했습니다.
- 책장 모양을 따라가는 그림자가 아래 페이지에 부드럽게 드리워집니다. 높이 들릴수록 진하고 멀어질수록 옅어집니다.
- 넘김이 시작·종료되는 순간에는 음영이 0으로 수렴해 정지 상태와 이어집니다.

개선 62 (책장 넘김 — 이음새·틈·끊김 제거):
- 넘어가는 책장을 24개 조각이 아닌 하나의 연속된 곡면(WebGL)으로 그립니다. 조각 사이 이음새와 틈이 생기지 않습니다.
- 책장의 안쪽(제본선) 가장자리는 항상 제본선에 붙어 있고, 책장은 그 지점에서부터 부드럽게 휘어집니다. 앞·뒤 방향 모두 동일합니다.
- 넘김 직전에 필요한 페이지 이미지를 미리 디코딩해 GPU에 올려 두어, 시작 순간의 멈칫거림을 없앴습니다.
- 매 프레임 전체를 다시 블러하던 drop-shadow 필터를 제거하고 실제 페이지에 고정 그림자를 적용했습니다.
- 드래그를 놓는 순간의 속도를 이어받아 안착하므로 속도 변화가 튀지 않습니다.
- WebGL2를 쓸 수 없는 브라우저는 이전 방식(book-turn-legacy.js)으로 자동 전환됩니다.
- 수정 파일: book-turn.js, book-turn-legacy.js(신규·예비), fit-layout.css, index.html(캐시 버전)

개선 61 (페이지 넘김 모션):
- 클릭·화살표 넘김을 0.42초 → 약 1.15초로 늘리고, 천천히 들리고 → 흐르고 → 내려앉는 ease-in-out 곡선으로 교체했습니다.
- 드래그 후 놓았을 때는 0.64~0.98초 동안 급감속 없이 안착합니다.
- 곡면 휘어짐이 속도에 덜 민감하도록 줄여 떨림을 없앴습니다.
- 연속 입력은 최대 2장까지 보존하며, 이어지는 넘김은 0.76초로 조금 빠르게 진행됩니다.
- 수정 파일: book-turn.js, index.html(캐시 버전 갱신)
